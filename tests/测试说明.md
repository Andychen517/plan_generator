# 研究目标生成器 · 测试说明(给测试者)

一个脚本:喂一份「研究现状/文献综述」→ 自动产出「研究目标」,并给出完整溯源。

## 一、准备(约 3 分钟)

1. **装 Python 3.10+**,然后装依赖:
   ```
   pip install openai python-dotenv reportlab
   ```

2. **填 API key**:把 `.env.example` 复制成 `.env.local`(就放在本文件夹里),
   填入你自己的 OpenRouter key(去 https://openrouter.ai/keys 免费注册领取):
   ```
   OPENAI_KEY=你的key
   OPENAI_ENDPOINT=https://openrouter.ai/api/v1
   CUSTOM_MODEL=deepseek/deepseek-r1-0528
   ```
   > 国内需给**终端**开代理(浏览器能开 openrouter.ai ≠ 终端能连):
   > PowerShell 里先执行 `$env:HTTPS_PROXY="http://127.0.0.1:端口"`(端口换成你代理的),同窗口再跑。

## 二、跑一次(测试指令)

```
python goal_gen.py tests\test_review_imputation.txt "面向多元时间序列缺失值插补,提出更贴近真实场景、可扩展、可靠的深度学习插补方法"
```
- 第 1 个参数:研究现状 txt(tests\ 里自带:`test_review_imputation.txt` 时序插补 / `test_review_ml.txt` 儿童词汇 / `test_review.txt` 教育惩戒)
- 第 2 个参数:研究方向(引导用)
- 跑一次约几十秒到几分钟(模型 deepseek-r1 偏慢,脚本会自动重试断连)

## 三、看结果:全部中间产物 + 一份 PDF 报告

跑完后,`output\` 文件夹里有全过程:

| 文件 | 内容 |
|---|---|
| units.json | A 抽的方法单元 |
| gaps.json | B 抽的研究空白 |
| gaps_merged.json | 去重合并后的空白 |
| candidates.json | C 的候选研究目标 |
| reflections.json | 反思的逐条判定 |
| tournament.json | 锦标赛排名 |
| research_goal.txt | **最终研究目标(成稿)** |

**生成一份 PDF 溯源报告**(把上面全串起来,原文→单元→空白→候选→成稿→排名):
```
python make_report.py tests\test_review_imputation.txt
```
→ 得到 `goal_traceability.pdf`(和 `goal_traceability.html`)。包里附了一份样例。

## 四、想验证"每一步真的靠谱"?跑负对照

```
python tests\test_reflect.py    # 造带缺陷的候选,看反思能不能挑出硬伤
python tests\test_dedup.py      # 造重复的空白,看去重能不能合并
python tests\test_tourney.py    # 造一强一弱,看排序对不对
```
终端会打对分表,✓ 越多越好。

## 五、流程一览

```
A 拆解现状 → B 抽空白 → 去重 → C 转候选 → 反思(淘汰硬伤) → D 扩写成稿 → 锦标赛(排序)
```
反馈问题的话,把终端输出 + `output\` 里的 json 发回来即可。
